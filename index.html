📊 結算工具

/kol-settle
KOL 結算金額計算

只需把 HB 社群賣場匯出的 CSV 拖進對話，AI 自動計算 K 欄商品結算金額總和， 智慧排除「已取消」訂單，即時給出有效筆數與總金額。

  • 讀取 CSV 的 K 欄（商品結算金額）
  • 自動排除 F 欄標示「已取消」的訂單
  • 空白狀態子行正確保留計入
  • 回報有效行數、排除行數、K 欄總金額
  • 無需安裝任何軟體，直接在 Claude 對話中操作
  • 支援任意行數，千筆資料秒速計算

使用方式

只需要 Claude Code，不需要任何額外設定

1

開啟 Claude Code

在終端機輸入 claude 啟動 Claude Code 互動介面

2

輸入指令

輸入 /morning 取得晨報，或 /kol-settle 計算結算金額

3

附上檔案（KOL）

使用 /kol-settle 時，將 CSV 檔案拖曳到對話視窗即可

4

取得結果

AI 自動處理並以繁體中文格式化輸出，可直接複製使用
